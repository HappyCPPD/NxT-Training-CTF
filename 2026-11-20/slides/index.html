TOOL 1 OF 3 · CRYPTO

CyberChef

The cyber Swiss Army knife, built by GCHQ (the UK’s spy agency) and free for everyone. If text looks scrambled, CyberChef can probably unscramble it.

THE KITCHEN

Four boxes. That’s the whole tool.

1 · OPERATIONS

The menu. Search for what you want, like From Base64.

2 · RECIPE

Drag operations here. They run top to bottom, one after another.

3 · INPUT

Paste text, or click the folder icon to open a file.

4 · OUTPUT

Updates live. If it looks readable, you’re done.

  • A recipe is like a playlist of steps. Order matters.
  • Drag the wrong thing in? Drag it back out, or click the trash icon.
  • The magic wand icon next to Output means CyberChef has a guess for you. Click it.

SKILL #2 · CHAINING

Layers? Peel one at a time.

By hand

  2. Add From Base64. Now it’s only 0–9 a–f…
  3. So add From Hex below it

With Magic

  1. Search Magic, drag it in
  2. It tries many decodings and ranks the readable ones
  3. Click a result to load its recipe

SKILL #3 · KEYS

Real ciphers need a key

Vigenère (1553)

Like ROT13, but every letter shifts by a different amount, set by a keyword.

Acmbh xa zs Lpc Oz Spb

Recipe: Vigenère Decode, key PIZZA

XOR

Flips bits using the key. Doing it twice with the same key undoes it.

20243b226b38222e3c6b2f2a22

Recipe: From Hex, then XOR with key K (set to UTF8)

No key? Look for it in the challenge. Companies love using obvious keys.

SKILL #4 · HASHES

A hash can’t be decoded. It can be looked up.

A hash is a one-way fingerprint. Websites store your password’s hash, not your password.

8621ffdbc5698829397d97767ac13db3

32 hex characters usually means MD5.

Try it

  1. Open crackstation.net
  2. Paste the hash, do the captcha
  3. It finds the word in a giant table of already-hashed passwords

Common password = cracked in a second. That’s why sites add a random salt before hashing.

SKILL #7 · METADATA

Photos remember where you were

Phones save hidden notes in every photo: camera model, time and often GPS coordinates. This is called EXIF.

Try it: holiday_photo.jpg

  1. CyberChef: open the file
  2. Add Extract EXIF
  3. Find GPSLatitude and GPSLongitude
  4. Paste them into Google Maps

SKILL #8 · BIT PLANES

Your eyes can’t see the last bit

sunset.png, as you see it

Red, bit plane 0 on aperisolve

Every pixel is a number from 0 to 255. Changing 200 to 201 is invisible, but the last bit flipped. Hide a message there and nobody notices. That’s steganography.

Try it: upload sunset.png to aperisolve.com and scroll to the bit planes.

SKILL #9 · FILES INSIDE FILES

A viewer stops reading early. The file doesn’t end there.

THE PICTURE

What your photo viewer reads, up to its “end of image” marker

EXTRA

Bytes after the end. Ignored by viewers.

How to spot it

File size way bigger than the picture should be. A second set of magic bytes in the middle.

How to get it out

aperisolve’s binwalk section lists everything inside. Or try renaming a copy and opening it with 7-Zip.

SKILL #10 · SPECTROGRAMS

Don’t listen. Look.

A spectrogram draws sound: time left to right, pitch bottom to top, loudness as brightness. Shape the sound right and it draws a picture.

Try it: secret_song.wav

  1. dcode.fr → Spectral Analysis
  2. Untick Logarithmic scale, press play
  3. Or Audacity: track menu → Spectrogram

Open-source intelligence

SKILL #11 · REVERSE IMAGE SEARCH

where_is_this.jpg

Search with a picture

  1. Open lens.google.com, upload the photo
  2. Scroll the matches. Which place name keeps coming up?
  3. Crop to one detail (a sign, a roof, a logo) and search again
  4. Confirm it in Google Maps before you submit

Lens not sure? Try Bing Visual Search or TinEye.

SKILL #12 · MAPS AND STREET VIEW

Google Maps is an investigation tool

COORDINATES

Paste numbers like 1.2868, 103.8545 into the search bar. It drops a pin there.

STREET VIEW

Drag the little yellow person onto a road. Walk around. Match the buildings to your photo.

TIME TRAVEL

On a computer, Street View’s top-left box can show older photos of the same spot. Places change.

Street signs, shop names, languages and road markings are all clues. Write every one down.

SKILL #13 · THE WAYBACK MACHINE

The internet doesn’t forget

The Internet Archive has been saving copies of websites since 1996. Billions of pages.

web.archive.org

Deleted page? Changed About Us? Old prices? It’s often still there.

Try it: google.com

  1. Type google.com into the Wayback search
  2. Drag the timeline all the way left
  3. Click the earliest circled date on the calendar
  4. What did Google look like? When was it first saved?
